You are given a 2D integer array `threats`, where each <code>threats[i] = [ID<sub>i</sub>, sev<sub>i</sub>​, exp<sub>i</sub>]</code>

- <code>ID<sub>i</sub></code>: Unique identifier of the threat.
- <code>sev<sub>i</sub></code>: Indicates the severity of the threat.
- <code>exp<sub>i</sub></code>: Indicates the exploitability of the threat.

The score of a threat `i` is defined as: <code>score = 2 × sev<sub>i</sub> + exp<sub>i</sub></code>

Your task is to return `threats` sorted in descending order of score.

If multiple threats have the same score, sort them by ascending ID​​​​​​​.
