You are given an integer array `nums` of length `n` and an array `queries`, where <code>queries[i] = [l<sub>i</sub>, r<sub>i</sub>, threshold<sub>i</sub>]</code>.

Return an array of integers `ans` where `ans[i]` is equal to the element in the subarray <code>nums[l<sub>i</sub>...r<sub>i</sub>]</code> that appears at least <code>threshold<sub>i</sub></code> times, selecting the element with the highest frequency (choosing the smallest in case of a tie), or `-1` if no such element exists.
