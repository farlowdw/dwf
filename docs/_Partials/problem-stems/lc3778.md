You are given a positive integer `n` and a 2D integer array `edges`, where <code>edges[i] = [u<sub>i</sub>, v<sub>i</sub>, w<sub>i</sub>]</code>.

There is a weighted connected simple undirected graph with `n` nodes labeled from `0` to `n - 1`. Each <code>[u<sub>i</sub>, v<sub>i</sub>, w<sub>i</sub>]</code> in `edges` represents an edge between node <code>u<sub>i</sub></code> and node <code>v<sub>i</sub></code> with positive weight <code>w<sub>i</sub></code>.

The cost of a path is the sum of weights of the edges in the path, excluding the edge with the maximum weight. If there are multiple edges in the path with the maximum weight, only the first such edge is excluded.

Return an integer representing the minimum cost of a path going from node `0` to node `n - 1`.
