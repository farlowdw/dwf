You are given a string `s` of length `m` consisting of digits. You are also given a 2D integer array `queries`, where <code>queries[i] = [l<sub>i</sub>, r<sub>i</sub>]</code>.

For each `queries[i]`, extract the substring <code>s[l<sub>i</sub>..r<sub>i</sub>]</code>. Then, perform the following:

- Form a new integer `x` by concatenating all the non-zero digits from the substring in their original order. If there are no non-zero digits, `x = 0`.
- Let `sum` be the sum of digits in `x`. The answer is `x * sum`.

Return an array of integers `answer` where `answer[i]` is the answer to the `i`th query.

Since the answers may be very large, return them modulo <code>10<sup>9</sup> + 7</code>.
